# UB: Хотын Домог _(түр нэр)_

Улаанбаатараас санаа авсан **оригинал** open-world action-adventure тоглоом: 3-р этгээдийн камер,
машин жолоодох, даалгавартай. Вэб хөтөч дээр ажиллана (Three.js + Rapier физик).
Бүх дүр, газар, нэр, хөгжим, текстур өөрсдийн зохиосон — ямар нэг тоглоомын хуулбар биш.

> **Одоогийн төлөв: Үе шат 5 — Хайлтын түвшин ба цагдаа** ✅
> Үе шат 1: явган дүр (Бат), 3-р этгээдийн камер, WASD.
> Үе шат 2: "Хибрид" машин (жолоо баруун талдаа), **F** суух/буух, raycast жолоодлогын физик, сургалтын талбай.
> Үе шат 3: 7 дүүрэгтэй хот, гол + 3 гүүр, тойрог, мини газрын зураг, **M** том газрын зураг, GPS маршрут.
> Үе шат 4: хотын хүн ам — замын хөдөлгөөн (гэрлэн дохио, дүрэм, түгжрэл), явган хүмүүс, Монгол яриа,
> **F** — бусдын машиныг булаах.
> Үе шат 5: хайлтын түвшин (1–5 од), цагдаагийн машин (анивчдаг гэрэлтэй), хөөцөлдөөн, явган цагдаа,
> баривчлагдах / зугтах.

## Ажиллуулах

**Шаардлага:** [Node.js](https://nodejs.org) 18 буюу түүнээс дээш (Node 24 дээр шалгасан),
WebGL дэмждэг хөтөч (Chrome, Edge, Firefox-ийн сүүлийн хувилбар).

```bash
npm install
```

```bash
npm run dev
```

Терминалд гарсан хаягийг (`http://localhost:5173`) хөтөч дээр нээгээд **Тоглох** дарна.

| Команд            | Үйлдэл                                                        |
| ----------------- | ------------------------------------------------------------- |
| `npm run dev`     | Хөгжүүлэлтийн сервер (код хадгалахад хуудас автоматаар шинэчлэгдэнэ) |
| `npm run build`   | `dist/` хавтаст оновчилсон хувилбар үүсгэнэ                  |
| `npm run preview` | `dist/`-ийг локал сервер дээр шалгана                         |

> `index.html`-ийг шууд давхар дарж (file://) нээвэл ажиллахгүй — заавал `npm run dev` ашиглана.

## Хайлтын түвшин ба цагдаа (Үе шат 5)

| Хэрэг | Оноо |
| --- | --- |
| Явган хүн мөргөж унагаах (цусгүй — босоод зугтана) | 1 |
| Замын хөдөлгөөний машин булаах (F) | 1 |
| Машин хүчтэй мөргөх (> 6 м/с) | 0.5 |
| Цагдаагийн нүдэн дээр улаан гэрлээр гарах | 1 |
| Цагдаагийн машин мөргөх (тоглогч мөргөсөн тохиолдолд) | 1.5 |
| Цагдаа мөргөж унагаах | 2 |
| Цагдаагийн машин хулгайлах | 2 |

- **Од:** 1★ = 1 оноо, 2★ = 3, 3★ = 6, 4★ = 10, 5★ = 15. Цагдаа харж байхад удаан хөөгдвөл 3★ хүртэл аажмаар өснө.
- **Цагдаагийн тоо:** 1★ — 1 машин, 2★ — 2, 3★ — 3 (мөргөж зогсооно), 4★ — 4 (жийп нэмэгдэнэ), 5★ — 6.
  Замын хөдөлгөөнд эргүүлийн машин явдаг — хэрэг гарвал хамгийн ойрын эргүүл шууд хөөнө.
- **Харагдах эсэх:** цагдаа 95 м хүртэл харна, гэхдээ барилгаар хаагдвал харахгүй (цацрагаар шалгана).
  Харагдахгүй болбол одод анивчиж, цагдаа **сүүлд харагдсан газрын** орчимд эрнэ (мини газрын зурагт
  улаан тойрог). 1★ — 15 сек, 5★ — 35 сек нуугдвал мөрөө алдана.
- **Баривчилгаа:** явган бол машин хажууд зогсож цагдаа бууж хөөнө (гүйж зугтаж болно — цагдаа 6.1 м/с,
  тоглогч 7 м/с); 1.3 сек барьвал баривчлагдана. Машинтай бол зогсоход цагдаагийн машин хаагаад
  2.5 сек-д баривчилна. Баривчлагдвал цагдаагийн хэлтсийн гадаа суллагдана (мөнгөний торгууль — Үе шат 8).
- Анивчдаг гэрэлтэй цагдаа араас ирэхэд замын машинууд баруун тийш зайлж зогсоно.
- Цагдаа машинаасаа буухад хоосон машиныг нь хулгайлж болно (хайлт өснө).

## Архитектур (товч)

**Тоглоомын давталт** (`core/Game.js`): кадр бүр _оролт → камер → физик → анимаци → зураг_.
Физик нь **тогтмол 60 Гц** алхмаар (accumulator), дүрслэхдээ хоёр алхмын хооронд **interpolation**.
Алхам бүрт: тоглогч → цагдаагийн жолооч → NPC (гэрлэн дохио, машин, явган хүн) → машинууд → `world.step()`.

**Замын хөдөлгөөн** (`npc/TrafficCars.js`): машин бүр эгнээ → уулзварын муруй → эгнээ замаар явна.
Хурдыг **IDM** (Intelligent Driver Model) тооцоолно — урд талын саад хүртэлх зай, хурдны зөрүүгээр
жигд хурдасна/тоормосолно. Улаан гэрэл, ээлжийн уулзварын "захиалга", тойргийн зам тавих дүрэм нь
зогсох шугам болж IDM-д ордог тул дараалал, **түгжрэл** аяндаа үүснэ. Уулзварын гарах эгнээ дүүрэн
бол уулзварт орохгүй (уулзварыг хаахгүй); огтлолцох хоёр машин бие биенээ харвал id-гаар ээлж тогтооно.

**Явган хүн** (`npc/Pedestrians.js`): блок бүрийн явган замын цагираг + уулзварын гарц. Гэрлэн
дохиотой гарцад машины урсгал улаан бөгөөд гарч дуусах хугацаа хангалттай үед л гарна. Хүн замын
цэг рүү "хөөцөлдөж" хөдөлдөг тул булан эргэх, унасны дараа буцах нь жигд. 6 InstancedMesh → 6 draw call.

**Цагдаа** (`police/`): `WantedSystem` нь зөвхөн төлөв (оноо, од, харагдах, хайлт), `PoliceManager`
нь нэгжүүдийг удирдана, `PoliceDriver` нь физик машиныг тоглогчийн адил оролтоор (хурдасгуур,
тоормос, жолоо) жолооддог тул цагдаагийн машин мөргөлдөж, хөмөрч, гулсаж болно.

**Хэл** (`i18n/`): бүх текст `mn.json` / `en.json`-д (NPC-ийн яриа ч мөн — `tList('npc.bump')`).

### Гүйцэтгэл (60 FPS)
- Давтагддаг объект **InstancedMesh** (барилга, мод, NPC машин, явган хүн, гэрлэн дохионы чийдэн).
- Хот 240 м-ийн хэсгүүдэд (chunk) хуваагдсан, LOD-той; сүүдэр зөвхөн тоглогчийн эргэн тойронд.
- NPC: орон зайн хэш (16 м нүд) — "урд минь хэн байна" хайлт хурдан; хол (машин 345 м, хүн 175 м)
  гарсныг арилгаж, ойр орчинд камерт харагдахгүй газарт шинээр гаргана.
- Хэмжилт (хөтөч дээр): 42 машин + 50 хүн — физик+NPC алхам ≈ 0.6 мс; 5★ хөөцөлдөөн (6 цагдаа) —
  кадрын логик ≈ 0.75 мс; хот ≈ 185 draw call.

### Rapier 0.21-ийн анхаарах зүйлс (кодонд шийдсэн)
- Хавтгай шал руу налуу хөдөлгөөнд KCC хааяа гацдаг → газар дээр босоо хөдөлгөөнийг 0 болгож,
  газар дагахыг өөрсдөө (shape cast) хийсэн.
- Хэт том cuboid газар нарийвчлал алддаг; HalfSpace KCC-ийг дээш түлхдэг → 320 м-ийн хавтангууд.
- Тоглоомын явцад үүсгэсэн машины (цагдаа, булаасан машин) биеийг `updateVehicle` + `world.step()`
  эхний алхамд "идэвхгүй" болгодог → `Vehicle.fixedUpdate` бие идэвхгүй бол дахин идэвхжүүлнэ.

## Дараагийн алхам — Үе шат 6

Даалгаврын систем (`src/missions/`) + эхний 3 даалгавар: зорилт, GPS тэмдэг, дүрүүдийн яриа,
амжилт/бүтэлгүйтэл, шагнал.

Хөгжүүлэлтийн үед хөтчийн консолоос `__game` объектоор тоглоомын төлөвийг шалгаж болно
(жишээ нь `__game.player.position`, `__game.wanted.level`, `__game.npc.stats`).
