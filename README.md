# UB: Хотын Домог _(түр нэр)_

Улаанбаатараас санаа авсан **оригинал** open-world action-adventure тоглоом: 3-р этгээдийн камер,
машин жолоодох, даалгавартай. Вэб хөтөч дээр ажиллана (Three.js + Rapier физик).
Бүх дүр, газар, нэр, хөгжим, текстур өөрсдийн зохиосон — ямар нэг тоглоомын хуулбар биш.

> **Одоогийн төлөв: Үе шат 3 — Хот ба газрын зураг** ✅
> Үе шат 1: явган дүр (Бат), 3-р этгээдийн камер, WASD.
> Үе шат 2: "Хибрид" машин (жолоо баруун талдаа), **F** суух/буух, raycast жолоодлогын физик,
> хурд хэмжигч, сургалтын талбай (конус, трамплин).
> Үе шат 3: 7 дүүрэгтэй хот (`src/city/`), гол + 3 гүүр, тойрог, гэрлэн дохио, троллейбусын утас,
> мини газрын зураг (доод зүүн), **M** — том газрын зураг, дарж зорих цэг тавихад GPS маршрут (A*).
>
> Нэмэлт удирдлага: машинд **W/S** хурдлах/тоормос-ухрах, **A/D** жолоо, **Space** гар тоормос,
> **F** буух; жойстикт RT/LT, RB, Y. Шинэ хавтас: `src/vehicles/`, `src/city/`, `src/navigation/`,
> `src/ui/MapUI.js`. Хотын бүх өгөгдөл `src/city/cityLayout.js`-д.
>
> Шалгасан (хөтөч дээр, 60 Гц): 0→100 км/ц ≈ 6 сек, 100→0 км/ц ≈ 37 м, ямар ч хурдад эргэлтэнд
> хөмрөхгүй, хөмөрсөн машин 2.5 сек-ийн дараа өөрөө эргэнэ; хот 751 барилга, ≈160–210 draw call,
> 60 FPS; гүүр, хашлага, GPS маршрут (голыг гүүрээр гатална) зөв ажилласан.

## Ажиллуулах

**Шаардлага:** [Node.js](https://nodejs.org) 18 буюу түүнээс дээш (Node 24 дээр шалгасан),
WebGL дэмждэг хөтөч (Chrome, Edge, Firefox-ийн сүүлийн хувилбар).

```bash
npm install
```

```bash
npm run dev
```

Терминалд гарсан хаягийг (`http://localhost:5173`) хөтөч дээр нээгээд **Тоглох** дарна.

| Команд            | Үйлдэл                                                        |
| ----------------- | ------------------------------------------------------------- |
| `npm run dev`     | Хөгжүүлэлтийн сервер (код хадгалахад хуудас автоматаар шинэчлэгдэнэ) |
| `npm run build`   | `dist/` хавтаст оновчилсон хувилбар үүсгэнэ                  |
| `npm run preview` | `dist/`-ийг локал сервер дээр шалгана                         |

> `index.html`-ийг шууд давхар дарж (file://) нээвэл ажиллахгүй — заавал `npm run dev` ашиглана.

## Удирдлага

| Товчлуур             | Үйлдэл                                    | Жойстик (Xbox / PlayStation) |
| -------------------- | ----------------------------------------- | ---------------------------- |
| **W A S D** / сум    | Хөдлөх (камерын харж буй зүгт харьцангуй) | Зүүн стик                    |
| **Shift**            | Гүйх                                      | B / ○ эсвэл LB               |
| **Space**            | Үсрэх                                     | A / ✕                        |
| **Хулгана**          | Камер эргүүлэх                            | Баруун стик                  |
| **Хулганы дугуй**    | Камер ойртуулах / холдуулах               | —                            |
| **Esc** (эсвэл P)    | Түр зогсоох цэс                           | Start                        |
| **F3**               | FPS, байрлал, draw call харуулах          | —                            |
| **F4**               | Физикийн collider-уудыг утсан хүрээгээр   | —                            |
| F / E / M / Tab      | _Машин / харилцах / газрын зураг / утас — дараагийн үе шатуудад_ | Y / X / Back / ↑ |

- Товчлуурыг **физик байрлалаар** (`event.code`) танидаг тул компьютер **монгол кирилл** гарын
  байрлалтай байсан ч WASD ажиллана.
- Эхний дарахад хулгана "түгжигдэнэ" (pointer lock). Esc дарвал суллагдаж, цэс нээгдэнэ.
  Pointer lock ажиллахгүй орчинд хулганаа **дарж чирэх**-ээр камер эргэнэ.
- Тохиргоо (хэл, хулганы мэдрэмж, Y тэнхлэг урвуулах, FPS) хөтчид хадгалагдана.

## Архитектур (товч)

**Тоглоомын давталт** (`core/Game.js`): кадр бүр _оролт → камер → физик → анимаци → зураг_.
Физик нь **тогтмол 60 Гц** алхмаар явдаг (accumulator) тул 30, 60, 144 Гц дэлгэц дээр
тоглоомын мэдрэмж ижил. Дүрийг дүрслэхдээ хоёр физик алхмын хооронд **interpolation** хийдэг.

**Тоглогч** (`player/Player.js`): Rapier-ийн kinematic character controller — хана дагуу гулсах,
0.4 м хүртэлх шат/хашлага дээр автоматаар гарах, 50° хүртэлх налуу өгсөх. Доош налуу, шатаар
буухад газарт наалдахыг өөрсдийн shape cast (`snapToGround`) хийнэ. Coyote time (ирмэгээс унасны
дараахан ч үсэрч болно) ба jump buffer (газардахаас өмнөхөн дарсан Space-ийг санах) бий.

**Камер** (`player/ThirdPersonCamera.js`): дүрийг тойрон эргэнэ; дүр ба камерын хооронд хана,
барилга орвол цацраг шидэж камерыг урагшлуулна. Мод, шон зэрэг жижиг саадыг үл тооно
(мөргөлдөөний бүлэг `GROUP.PROP`).

**Хэл** (`i18n/`): бүх текст `mn.json` / `en.json`-д. HTML дээр `data-i18n="түлхүүр"`,
JS дээр `t('түлхүүр')`. 3D ертөнц дэх самбар хүртэл хэл солигдоход шинэчлэгдэнэ.

**Түр ассетууд**: бүх дүрс энгийн геометр. Жинхэнэ загвар (GLTF) оруулахдаа зөвхөн
`PlayerModel.js` (дүр) ба `world/props.js` (объектууд) доторх функцуудыг солино —
тэдгээрийн гадаад интерфэйс (`root`, `animate()` г.м.) хэвээр үлдэнэ.

### Гүйцэтгэл (60 FPS)
- Давтагддаг объект **InstancedMesh** (70 мод = 2 draw call, 12 шон = 3), уулс нэг geometry.
- Статик объектын матрицыг нэг л удаа тооцоолно (`matrixAutoUpdate = false`).
- Сүүдэр зөвхөн тоглогчийн эргэн тойронд (±40 м), чичрэхгүйн тулд texel-д тааруулна.
- Pixel ratio ≤ 2, frustum culling (Three.js анхдагч), түр зогссон үед дахин зурахгүй.
- Үе шат 1-ийн үзүүлэлт: ~140 draw call, ~11 мянган гурвалжин.

## Үе шат 1-д шалгасан зүйлс

Хөтөч дээр тоглоомын давталтыг 60 Гц-ээр автоматаар ажиллуулж шалгасан:

| Тест | Үр дүн |
| --- | --- |
| Алхах / гүйх хурд | 3.2 м/с / 7.0 м/с, тэгш газар дээр гацалт 0 |
| Үсрэлт | 1.18 м өндөр, агаарт 0.62 сек |
| Шатаар өгсөх, буух (8 × 0.25 м), алхах ба гүйх | Тавцанд хүрсэн, "агаарт" кадр 0 |
| 16° налуугаар өгсөх, буух | Тавцанд хүрсэн, агаарт кадр 0 |
| 0.15 м хашлага (талбайн ирмэг) | Автоматаар гарч, бууна |
| 1 м хайрцаг дээр гүйж үсрэх | Дээр нь газардсан |
| Хана руу алхах | Зогсоно, хөлний анимаци зогсоно |
| 2 м тавцангаас алхаж унах | Унаад газардана |
| Камер хананы ард орох | 5.2 м → 0.9 м болж урагшилна |
| Газраас доош унах | Эхлэлийн цэг рүү буцна |
| Монгол ↔ English | UI, HUD, 3D самбар бүгд солигдож, тохиргоо хадгалагдана |
| `npm run build` | Алдаагүй |

### Rapier 0.21-ийн анхаарах зүйлс (кодонд шийдсэн)
- Хавтгай шал руу налуу (урагш + доош) хөдөлгөөн өгвөл KCC хааяа хөдөлгөөнийг бүхэлд нь
  тасалдаг → газар дээр байхад босоо хөдөлгөөнийг 0 болгож, газар дагахыг өөрсдөө хийсэн.
- Хэт том cuboid (±2000 м) газар дээр shape cast ~15 см алддаг; HalfSpace нь KCC-ийг огцом дээш
  түлхдэг → газрын collider тоглох талбайн хэмжээтэй (±320 м).

## Дараагийн алхам — Үе шат 2

Нэг машин (жижиг хибрид суудлын машин), **F**-ээр суух/буух, Rapier-ийн
`DynamicRayCastVehicleController` дээр суурилсан жолоодлогын физик, машины ард дагах камер.

Хөгжүүлэлтийн үед хөтчийн консолоос `__game` объектоор тоглоомын төлөвийг шалгаж болно
(жишээ нь `__game.player.position`).
